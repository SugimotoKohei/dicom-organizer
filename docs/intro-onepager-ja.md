# 手元の DICOM 整理と撮像条件の確認ツール: dicom-organizer 紹介シート

この資料は、院内の同僚、研究室のメンバー、勉強会等で `dicom-organizer` を紹介するための 1 枚まとめシートです。

---

## 1. 何ができるツールか？

外付けメディア、CD-R、装置コンソール等から取り出した **バラバラの DICOM フォルダ** を、手元の PC で安全に整理し、撮像パラメータの一覧表（CSV）を自動作成するオープンソースツールです。

- **日付とシリーズごとに自動仕分け**: `装置名/検査日/シリーズ番号_系列名/` のきれいなフォルダ階層にコピーします。
- **撮像条件を CSV に一発集約**: TR、TE、フリップ角、スライス厚、位相エンコード方向、パラレル倍速数などを 1 つの表にまとめます。
- **重複や破損ファイルを透明に報告**: 同一内容の重複コピーや非 DICOM ファイルを自動判別し、レポート（`file_report.csv`）に残します。
- **巨大データの棚卸しに**: 画像をコピーせず、撮像条件の CSV だけを高速に作る「一覧のみモード（`--list-only`）」も備えています。

---

## 2. どんな人・仕事向けか？

- **診療放射線技師**:
  - 複数メーカー（Canon / GE / Philips / Siemens）の MR 撮像プロトコルや設定値の整合性を比較・確認したいとき。
- **医用画像研究者・医師**:
  - コホート画像データから、特定の撮像条件（スライス厚や TE など）を満たす症例・シリーズをすばやく抽出したいとき。
- **画像解析・エンジニア**:
  - 3D Slicer や dcm2niix で解析・変換を回す前の、データ前処理と読めないファイルや重複の把握に。

## 3. かんたんな始め方

### デスクトップアプリ版（Python 不要・おすすめ）
1. [GitHub Releases](https://github.com/SugimotoKohei/dicom-organizer/releases) から zip をダウンロードして展開。
2. アプリを起動し、整理したい DICOM フォルダをドラッグ＆ドロップ。
3. まずは初期画面の「**サンプルデータで試す**」を押すと、安全なダミーデータで動作を体験できます。
※ バージョン 0.2.0 から単体アプリが提供されます。

### Python コマンドライン版
```bash
# インストール（uv を推奨）
uv tool install dicom-organizer

# 整理を実行
dicom-organizer /path/to/dicom-folder

# パラメータ一覧だけ作成（コピーなし・高速）
dicom-organizer /path/to/dicom-folder --list-only
```

---

## 4. 大事な注意点（安全のために）

- **医療機器ではありません**: 診断や臨床判断には使用できません。研究およびデータ管理専用です。
- **完全ローカル動作**: 外部ネットワークへの通信は一切行いません（院内ネットワークやオフライン PC でも安全）。
- **元データは変更しません**: 入力ファイルは読み取り専用で扱い、上書きや削除はしません。
- **DICOM 画像自体は匿名化されません**: コピーされた DICOM ファイルのヘッダーには患者情報が残ります。外部へ共有する際は、必ず施設承認の匿名化ツールを通してください。
